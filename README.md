# موتور رتبه‌بندی آگهی‌های اجاره دیوار

آگهی‌های اجاره را از دیوار می‌گیرد، همه را به **رهن کامل معادل** تبدیل می‌کند،
با median بازار مقایسه می‌کند و رتبه‌بندی‌شده نشان می‌دهد — روی نقشه و در جدول.

- مشخصات پروژه: [docs/SPEC.md](docs/SPEC.md)
- پلن اجرایی: [docs/PLAN.md](docs/PLAN.md)
- نقشه‌ی API دیوار: [docs/DIVAR_API.md](docs/DIVAR_API.md)

## راه‌اندازی

```bash
pip install requests fastapi uvicorn python-dotenv apscheduler
npm install
npm run css
python -m uvicorn web.app:app --port 8420
```

سپس <http://localhost:8420>. هنگام کار روی ظاهر، `npm run css:watch` را کنارش باز بگذارید.

## بات تلگرام

بهترین آگهی‌ها را در گروه پست می‌کند، با دکمه‌ی حذف و بوکمارک. سطل آشغال و
بوکمارک بات **همان** دیتابیس پنل است.

راه‌اندازی:

```text
۱. در BotFather یک بات بسازید و توکن را در .env بگذارید: TELEGRAM_BOT_TOKEN=...
۲. بات را به گروه اضافه و ادمین کنید (اجازه‌ی Delete messages)
۳. اجرا:  python -m divar_demo.bot
۴. در گروه /id بزنید؛ شناسه‌ی گروه (عدد منفی) را در .env بگذارید: TELEGRAM_CHAT_ID=-100...
۵. بات را دوباره اجرا کنید. برای همیشه‌روشن ماندن، run_bot.cmd را در Task Scheduler
   با «At log on» و «Restart on failure» بگذارید.
```

- فاصله‌ی اجرا و حداقل امتیاز از **پنل** تنظیم می‌شوند (بخش «بات تلگرام» در
  سایدبار). بات هر دقیقه دیتابیس را می‌خواند؛ ری‌استارت لازم نیست.
- چه چیزی پست می‌شود: آگهی **جدید** با امتیاز ≥ آستانه (پیش‌فرض ۷۰)، حداکثر ۱۰ تا
  در هر دور. اجرای اول فقط ۱۰ تای برتر را می‌فرستد و بقیه را «دیده‌شده» ثبت
  می‌کند تا گروه سیل نگیرد. ارزان‌شدن آگهی پست‌شده به‌صورت reply روی همان پست.
- عکس آگهی با پست می‌آید مگر آگهی‌دهنده گفته باشد عکس تزئینی است.
- دستورها: `/run` `/status` `/bookmarks` `/trash` `/mute 2h` `/searches` `/id`
- ‏`/bookmarks` هر بار زنده از دیتابیس ساخته می‌شود و می‌گوید قیمت از زمان بوکمارک
  چقدر تغییر کرده و آگهی هنوز در دیوار هست یا نه.

`python -m divar_demo.notify --dry-run` همچنان برای اجرای دستی یک‌باره کار می‌کند.

## استفاده

روی نقشه مستطیل یا چندضلعی بکشید (یا در سایدبار نام محله را بنویسید)، فیلترها را
تنظیم کنید و «جستجو» بزنید. هر ردیف با کلیک باز می‌شود و طبقه، امکانات و متن آگهی
را نشان می‌دهد. رنگ پین‌ها بر اساس فاصله از median بازار است.

خط فرمان هم کار می‌کند:

```bash
python -m divar_demo.main --size 80-150 --rooms 2 --credit-max 1500000000 --pages 2
```

## فرمول

```text
رهن کامل معادل = ودیعه + اجاره × (100 / 3)
```

هر ۱۰۰ میلیون ودیعه = ۳ میلیون اجاره. مقادیر `deposit` و `monthly_rent` هیچ‌وقت
overwrite نمی‌شوند.

## چه چیزی ساخته شده

- جستجوی نقشه‌ای با تقسیم بازگشتی محدوده — پوشش ۱۰۰٪ آگهی‌ها
- فیلتر چندضلعی دقیق روی مختصات
- فیلترهای قطعی سمت دیوار و سمت خودمان
- فیلتر «عکس واقعی ملک» — حدود ۲۹٪ آگهی‌ها عکس تزئینی دارند و حذف می‌شوند
- بیست‌وچند فیلتر اختیاری (تازگی آگهی، سن بنا، طبقه، گرمایش/سرمایش، بالکن،
  بازسازی، رهن معادل متری، حداقل عکس، فقط زیر median و …) — همه پیش‌فرض خاموش
- رهن کامل معادل و قیمت متری، با نرخ قابل تنظیم
- مقایسه با median و جدا کردن آگهی‌های بیش از حد ارزان
- تاریخچه‌ی قیمت و علامت «جدید»
- کش ۷ روزه‌ی جزئیات + دریافت موازی با محدودکننده‌ی نرخ
- پنل وب راست‌به‌چپ با نقشه، فیلتر، جدول مرتب‌شونده و جزئیات تنبل
- بات تلگرام: پست خودکار بهترین‌ها در گروه، دکمه‌ی حذف/بوکمارک، /bookmarks زنده
- امتیاز ۰ تا ۱۰۰ با تفکیک سهم هر معیار (قیمت نسبت به بازار، نوسازی، نزدیکی مترو)
- فاصله تا نزدیک‌ترین ایستگاه مترو (۱۲۴ ایستگاه تهران، از OpenStreetMap)
- سطل آشغال و بوکمارک با تب جداگانه — حذف قابل بازگردانی است
- پنهان کردن خودکار آگهی‌های هم‌خانه/هم‌اتاقی (قابل خاموش کردن)
- جستجوی بدون محله (کل شهر) و جستجوی محله از مسیر سریع نقشه
- جستجوی نقشه‌ای موازی (موج‌به‌موج): جستجوی یک محله حدود ۹ ثانیه
- کش نتیجه با عمر ۲ دقیقه فقط برای جلوگیری از کلیک‌های پشت‌سرهم، با دکمه‌ی
  تازه‌سازی که کش را دور می‌زند و برچسب «از کش، N ثانیه پیش»
- اسلایدر وزن معیارها (قیمت / نوسازی / مترو) با بازمحاسبه‌ی فوری سمت مرورگر
- اتصال جدول و نقشه: hover روی ردیف پین را برجسته می‌کند، کلیک روی پین ردیف را می‌آورد
- قیمت دقیق به ازای هر خانه‌ی نقشه — پوشش کامل در هر اندازه محدوده

## چه چیزی هنوز نیست

تشخیص آگهی تکراری، تحلیل متن آگهی، رگرسیون بازار (median فعلی با سقف قیمت کاربر سوگیری دارد).

## محدودیت‌های شناخته‌شده

- ‏median روی نتایج همان جستجو حساب می‌شود، پس سقف قیمت شما رویش اثر می‌گذارد.
  عدد «٪ بازار» یک تقریب است، نه واقعیت.
- پین‌های دیوار تقریبی‌اند (`approximate_location`)؛ فیلتر چندضلعی با تلورانس
  حدود ۲۰۰ متر کار می‌کند.
- کارت نقشه انباری، بالکن، طبقه و توضیحات ندارد — این‌ها با کلیک روی ردیف
  (صفحه‌ی جزئیات) می‌آیند.
- «عکس واقعی» حرف خودِ آگهی‌دهنده است، نه تشخیص تصویر. اگر کسی دروغ بگوید
  سیستم نمی‌فهمد؛ ولی ۲۹٪ که راستش را می‌گویند حذف می‌شوند.
- فاصله مترو **مستقیم** است نه پیاده‌روی، و پین دیوار هم تقریبی است. عدد را
  به‌عنوان تقریب بخوانید؛ خطای چند صد متری طبیعی است.
- شمارش دیوار روی ۱۰۰۰۰ اشباع می‌شود. در جستجوی کل شهر گاهی بیشتر از عدد
  گزارش‌شده جمع می‌کنیم.
- جستجوی کل شهر بدون فیلتر به سقف ۱۵۰ درخواست می‌خورد و «پوشش ناقص» نشان
  می‌دهد. فیلتر بگذارید یا محدوده بکشید.
- آگهی «توافقی» رهن معادل ندارد و در فیلتر قطعی حذف می‌شود.
- صفحه‌ی جزئیات دیوار بعد از ۳۰ درخواست ۴۲۹ می‌دهد (پنجره ~۳۰ ثانیه).
  محدودکننده‌ی نرخ نمی‌گذارد به آن برسیم.
- ‏«منطقه ۷» در دیوار وجود ندارد؛ فقط محله. برای منطقه باید محدوده کشید.
